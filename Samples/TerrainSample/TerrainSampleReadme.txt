Terrain Sample


This demo requires the following things of the Unity project:

Requires the Burst and InputSystem packages from Unity to be installed.

Requires the Player settings property "Allow 'unsafe' Code" to be enabled.

Requires the Player settings property "Active Input Handling" to be set to "Input System Package (New)" or "Both".


Additionally, it's recommended to set the Player settings property "Color Space" to "Linear".
